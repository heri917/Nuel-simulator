HAULING TRUCK SIMULATOR - PROTOTYPE 0.3

This is the first TRUE 3D gameplay foundation.

Current:
- Three.js 3D renderer
- 3D terrain, hills and forest
- 3D gravel road
- 3D disposal area
- 3D Volvo FMX 440 Trinton 8x4-style truck placeholder
- 4 axles / 8 wheels
- hubs, mirrors, windshield, grille, bumper, steps, exhaust, tank
- blue/yellow unit livery
- unit number 204
- third-person chase camera
- gas, brake and steering
- dumping animation
- trip counter
- PWA manifest/service worker
- iOS/Android home-screen target

The supplied truck photos are the visual reference for the next detailed asset pass. The current 3D truck is deliberately procedural and not claimed to be an exact scanned/modelled replica.

Important:
- Upload files at ZIP ROOT to GitHub Pages.
- Three.js is loaded from jsDelivr, so the first online load needs internet.
- For true offline gameplay, the Three.js library must later be bundled locally.
